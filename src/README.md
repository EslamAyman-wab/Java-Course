# Source Layout

This source root is split into three intentional areas:

| Directory | Meaning |
| --- | --- |
| `A_Course` | Official Java Masterclass code and challenges. |
| `B_Exercises` | External practice from CodingBat, W3resource, and similar sources. |
| `D_Test_Area` | Manual experiments and sandbox code. |

Use `docs/notion-course-map.md` from the repository root for the Notion-backed section mapping.
