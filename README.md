# Java-Course

## Overview
This repository is a comprehensive collection of Java programming exercises, challenges, and solutions, covering fundamental to advanced Java concepts. It is designed as a progressive learning resource and practice platform for mastering Java programming.

## Repository Structure

### 📂 Main Directories

#### `src/Rebild.A_Course/A_Challenges` — Programming Challenges
- **A_Ch**: Basic challenges (Ch_01.java – Ch_11.java)
  - Topics: unit conversion, mathematical operations, basic algorithms
- **B_Ch**: Intermediate challenges by topic
  - Ch_12: Bank account operations
  - Ch_13: Customer management
  - Ch_14: Student records
  - Ch_15: Employee management (inheritance, workers, salaried employees)
  - Ch_16: Smart kitchen simulation
  - Ch_17: Printer interface implementation
  - Ch_18: Car class implementation
  - Ch_19: Burger builder pattern
  - Ch_20: Advanced concepts
- **C_Ch**: Advanced challenges (Ch_23 – Ch_26)

#### `src/Rebild.A_Course/B_Coding_Exercise` — Structured Exercises
- **A_Ex** (Ex_01.java – Ex_10.java): Basic exercises (control flow, conditionals, simple logic)
- **B_Ex** (Ex_11.java – Ex_20.java): Intermediate exercises (arrays, loops, data manipulation)
- **C_Ex** (Ex_21.java – Ex_29.java): OOP basics
- **D_Ex** (Ex_30 – Ex_39): Advanced exercises with multiple classes
  - Ex_30: Simple calculator
  - Ex_31: Person class
  - Ex_32: Wall geometry
  - Ex_33: Point geometry
  - Ex_34: Carpet and floor calculations
  - Ex_35+: More advanced projects
- **E_Ex** (Ex_40+): Expert-level challenges

#### `src/Rebild.B_Exercises/A_CodingBat` — Array Problems
- **B_Arrays** (arr_01.java – arr_10.java): Array manipulation basics
- **C_Arrays** (arr_11.java – arr_12.java): Advanced array operations

#### `src/Rebild.D_Test_Area` — Testing & Experimentation
- Test files (Test_01.java – Test_04.java)
- Organized test directories (Test_05 – Test_08) for OOP and concept experimentation

#### `src/Rebild.B_Exercises/B_W3resource` — Additional Resources
- **A_Basics**: Fundamental Java concepts
- **E_oop**: OOP deep dives
  - A_constructor: Constructor patterns
  - H_Polymorphism: Polymorphism practices

## Key Topics Covered

- **Fundamentals**: Variables, data types, operators, control flow, methods
- **Object-Oriented Programming**: Classes, objects, inheritance, polymorphism, interfaces, constructors
- **Data Structures**: Arrays, collections, data manipulation
- **Design Patterns**: Builder pattern, interface-based design
- **Practical Applications**: Calculator, geometry, object relationships

## How to Use

1. **Learning Path**: Start with `A_Ch` (basic challenges), then progress through exercises in `B_Coding_Exercise`.
2. **Practice**: Solve exercises sequentially for skill progression.
3. **Experimentation**: Use `Rebild.D_Test_Area` for testing and exploring new concepts.
4. **Array Practice**: Focus on `A_CodingBat` for array problems.
5. **Reference**: Explore `B_W3resource` for OOP and Java fundamentals.

## Project Setup

- Java IntelliJ IDEA project
- Source code: `src/`
- Compiled output: `out/`
- Project file: `Java_Course.iml`

## Getting Started

1. Open the project in IntelliJ IDEA (or any Java IDE)
2. Navigate to any Java file in `src/`
3. Run files using the IDE runner or Java CLI
4. Review, modify, and implement solutions as needed
